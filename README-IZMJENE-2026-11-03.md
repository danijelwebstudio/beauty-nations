## Ugradnja

**Mali ZIP:** Kopirati sadržaj ZIP-a u postojeći folder `beauty-nation-2` i potvrditi zamjenu fajlova. Ne brisati `.vercel`, `.env.local` ili sopstvene lokalne promjene.

**Kompletan ZIP:** Može se otvoriti kao poseban projekat za pregled. Ako ga kopiraš preko postojećeg projekta, sačuvaj lokalna podešavanja i `.vercel` folder.

Lokalno: `npm install` (ako još nije urađeno), `npm run dev`, pa `npm run build`.

Po provjeri: `npx vercel --prod` iz foldera koji je povezan sa postojećim Vercel projektom.

NAPOMENA: Dodati tekst opisuje budući program finala. On NE implementira stvarni sistem glasanja ili video pozive – to je zasebna funkcionalnost (faza 2).
